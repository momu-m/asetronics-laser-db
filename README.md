# ALPA - Asetronics Laser-Programm-Archiv

Interne Web-Anwendung zur Verwaltung und Verteilung konvertierter
Laser-3-Programme (Asetronics AG, SMT-Produktion Bern).

## Zugriff

Die App ist unter folgender URL erreichbar:
https://momu-m.github.io/asetronics-laser-db/

## Technologie

- Frontend: HTML, Vanilla JS, CSS (kein Framework)
- Backend: Supabase (PostgreSQL + Auth + Storage)
- Hosting: GitHub Pages
